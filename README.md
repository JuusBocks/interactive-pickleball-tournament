# Live Pickleball Bracket

Mobile-friendly tournament bracket maker for live pickleball games.

Open the shared link, set up the tournament, and everyone viewing the bracket sees updates automatically as players or teams advance.

Live site: [live-pickleball-bracket.work-email-bruh.chatgpt.site](https://live-pickleball-bracket.work-email-bruh.chatgpt.site/)

## What It Does

- Creates a live tournament bracket that works from a phone browser.
- Supports both `1v1` singles tournaments and `2v2` doubles tournaments.
- Lets you add, edit, remove, and restore players before the tournament starts.
- Randomizes the order with Shuffle.
- In `2v2` mode, groups players into teams of two after shuffling.
- Locks the setup when the tournament starts so the bracket does not accidentally change mid-event.
- Lets the organizer tap `Win` on a match to advance that player or team.
- Updates all open phones automatically every few seconds.
- Shows wins, losses, byes, current rounds, and the pending or final champion.
- Includes a Copy Link button so the bracket can be shared quickly.

## Tournament Flow

1. Open the live site on your phone or laptop.
2. Choose `1v1` or `2v2`.
3. Add players one at a time, or paste/edit the full player list.
4. Tap `Save list`.
5. Tap `Shuffle` or `Shuffle teams`.
6. Tap `Start`.
7. For each match, tap `Win` on the player or team that won.
8. The winner automatically moves into the next round.
9. Everyone with the link sees the bracket refresh live.

## 1v1 Mode

Use `1v1` when each bracket entry is a single player.

Each player is seeded into the bracket individually. Winners advance one person at a time.

## 2v2 Mode

Use `2v2` when each match is team versus team.

Players are paired into teams of two. The app requires an even number of players before starting a doubles tournament. If there is one player without a partner, the setup panel shows a warning so another player can be added before the bracket is locked.

## Editing Before and After Start

Before starting:

- Add players.
- Remove players.
- Edit the full roster.
- Switch between `1v1` and `2v2`.
- Shuffle players or teams.
- Restore the default list.

After starting:

- Pick match winners.
- Clear picks if results need to be reset.
- Use `Edit setup` to unlock the roster if the tournament needs to be changed.

## Mobile Use

The app is designed for phones first:

- Large tap targets for match picks.
- Setup controls stack cleanly on small screens.
- Bracket rounds become easy vertical sections on mobile.
- Open screens keep syncing without manual refresh.
